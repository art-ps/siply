# Открытие файла из Finder и скрытие неиграемых файлов

## Зачем

Пользователь дважды кликает по музыкальному файлу в Finder и хочет сразу слушать его в Siply: в его папке, с остальными треками этой папки в очереди. Сейчас Siply не объявляет себя программой для аудиофайлов, и Finder не может открыть в нём файл.

Отдельно: в списке треков не должно быть файлов, которые Siply не сыграет.

## Поведение

### Открытие файла

1. Siply объявляет в Info.plist типы документов (роль Viewer, `LSHandlerRank` Alternate — не перехватываем у Music насильно) для тех же форматов, что показывает `LibraryScanner.audioExtensions`: mp3, m4a, aac, flac, wav, aif/aiff, caf. UTI: `public.mp3`, `public.mpeg-4-audio`, `public.aac-audio`, `org.xiph.flac`, `com.microsoft.waveform-audio`, `public.aiff-audio`, `public.aifc-audio`, `com.apple.coreaudio-format`. Задаётся через `info.properties` в `project.yml` (Info.plist генерирует xcodegen).
2. Двойной клик по файлу (Siply не запущен или запущен — одинаково):
   - корень библиотеки = папка файла, ровно как `Library.open(_:)` (⌘O): запоминается bookmark'ом, переживает перезапуск;
   - если корень уже равен этой папке — дерево не пересобирается, только `selection = root`;
   - в сайдбаре выбрана эта папка, справа её треки;
   - кликнутый трек начинает играть; очередь — все играемые треки папки в обычном порядке (`Track.sorted`), как при клике по треку в списке;
   - строка кликнутого трека выделена в таблице и прокручена в видимую область.
3. Несколько файлов за раз (выделили в Finder → «Открыть») — берём первый URL, остальные игнорируем. *Решение Claude.*
4. Приложение запущено, но окно закрыто → окно показывается снова. *Решение Claude.*
5. Файл открылся, но его нет среди играемых треков папки (неиграемый, неподдерживаемый, пропал) — папка открывается, ничего не играет, текущее воспроизведение не трогаем.

### Скрытие неиграемых файлов

6. `LibraryScanner.tracks(in:)` отбрасывает файлы, которые AVFoundation не сыграет: `AVURLAsset.load(.isPlayable) == false` или `hasProtectedContent == true` (DRM), либо загрузка свойства упала.
7. `FolderView` сначала показывает список по именам файлов (как сейчас), затем заменяет его загруженным — неиграемые исчезают в этот момент. Короткое мелькание допустимо.
8. Шапка папки (число треков, обложка) считается по отфильтрованному списку.

### Документация

9. README (en и ru) и сайт (ru и en): одна строка, как сделать Siply программой по умолчанию — Finder → «Свойства» (⌘I) → «Открыть в программе» → Siply → «Изменить всё».

## Проверки (тесты)

- `Library`: открытие файла меняет корень на его папку, выбор = корень, корень сохраняется в defaults (новый `Library` с тем же defaults видит его).
- `Library`: файл из папки, которая уже корень, — корень тот же объект/URL, `generation` не меняется.
- Открытие файла: плеер играет именно этот трек, очередь = все играемые треки папки в порядке `Track.sorted` (на `FakeAudioEngine`, реальные WAV из `AudioFixtures`).
- Открытие неиграемого файла: корень сменился, плеер не начал играть.
- Несколько URL — открывается первый.
- `LibraryScanner.tracks(in:)`: файл `.mp3` с мусором внутри отсутствует в результате, настоящий WAV — присутствует.
- Info.plist приложения содержит `CFBundleDocumentTypes` с перечисленными UTI.
- Все существующие тесты зелёные: `xcodegen generate >/dev/null && xcodebuild test -scheme Siply -destination 'platform=macOS,arch=arm64' -derivedDataPath build`.

Живой двойной клик из Finder — только если пользователь попросит: его запущенный Siply и UserDefaults не трогаем.

## Не делаем

- Не делаем Siply программой по умолчанию программно (macOS не даёт без действия пользователя).
- Нет drag & drop файлов в окно, нет «Открыть файл…» в меню.
- Нет режима «играть одиночный файл без папки», нет сохранения прежнего корня.
- Не расширяем список форматов (OGG, APE и т.п.).
- Релиз/версию не поднимаем — отдельно по просьбе.

## Оставлено исполнителю

- Как доставить URL в модели: `NSApplicationDelegateAdaptor` с `application(_:open:)` (рекомендация: делегат владеет `Library`/`PlayerModel` или получает их до первого открытия; URL, пришедший до готовности, буферизуется) или `onOpenURL` — главное, чтобы холодный старт и тёплый работали одинаково и SwiftUI не плодил новые окна.
- Как выделить и прокрутить строку в `TrackList` (например, выделять `player.currentTrack`, если он в загруженном списке папки, при загрузке папки).
- Где живёт логика «открыть файл» (метод на `Library`/небольшой тип) — так, чтобы она тестировалась без UI.
