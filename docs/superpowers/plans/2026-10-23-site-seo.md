# SEO сайта Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** закрыть пробелы SEO-аудита siply.top по спеке.

**Architecture:** статический `site/` (ru `index.html`, en `en/index.html`, общий `assets/style.css`), правки разметки + новые файлы в корне. Без сборки.

**Tech Stack:** HTML, CSS, JSON-LD, `cwebp`, `sips`.

**Spec:** `docs/superpowers/specs/2026-10-23-site-seo-design.md`

## Global Constraints

- Все строки текста, URL и значения — из спеки дословно.
- Дизайн 3c не ломать: новые блоки из существующих классов `site/assets/style.css`; новых правил CSS — минимум.
- Не трогать `#download` href и `#release` текст (их пишет `scripts/sync-site.sh`); `bash scripts/test-sync-site.sh` → OK после каждой задачи.
- Мобильная 390 px — без горизонтального скролла.
- Не пушить, коммиты без `Co-Authored-By`. Не трогать приложение Siply. Без новых зависимостей (cwebp и sips уже есть).

## Review Focus

- JSON-LD валиден и совпадает с видимым содержимым (featureList = заголовки карточек этой страницы).
- `404.html` открывается с любого пути: только абсолютные пути.
- `<picture>`: fallback jpg, width/height, `fetchpriority="high"`, en с `../assets/`.
