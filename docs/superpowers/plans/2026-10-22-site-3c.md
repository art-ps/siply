# Сайт 3c Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** лендинг `site/` в дизайне 3c (ru + en), статическая ссылка на DMG, `scripts/sync-site.sh`.

**Architecture:** статический HTML + один `site/assets/style.css` (классы вместо инлайн-стилей макета). Ссылка и строка версии вписаны в HTML; `sync-site.sh` переписывает их при релизе.

**Tech Stack:** HTML, CSS (`light-dark()`, `oklch`), bash/sed. Без сборки и зависимостей.

**Spec:** `docs/superpowers/specs/2026-10-22-site-3c-design.md`

Строка `<span id="release">Версия 1.2.1 · 0,8 МБ</span>` (en `Version 1.2.1 · 0.8 MB`) — размер из `build/release/Siply-1.2.1.dmg` (или `gh release view v1.2.1 --json assets`), формат `(size/1048576).toFixed(1)`, ru с запятой.
